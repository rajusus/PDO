Client Introduction

The client utility is used to play the actual game. The server alone cannot be used to play Space Merchant as it is only a console app.

Client is able to send data requests to servers and proceed to visualize the data for the user. You can interact with the system only using a client. You are able to buy offered trades or post their own trade offers. You can also manage your owned assets.

Note: Since the client is a console app, it will likely appear with a dark background when you run it on your pc. For the purposes of this tutorial, the colors were inverted so the background would appear light colored.
