# Entity Commands
Entities act as the actors in the simulation. You can modify them using these commands.

### Give Funds To Entity
To give credits to an entity, use this command.

```
GIVE_FUNDS_TO_ENTITY <entity_name> <funds_amount>
```

💰 Currency Note

In Space Merchant, "Funds" and "Credits" are used interchangeably. These are digital-only and are required for all Market Transactions and Node-to-Node transfers.
